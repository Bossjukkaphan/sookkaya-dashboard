# โฟลเดอร์เดโม่: ร้าน "บ้านกาแฟหอมละมุน"

ร้านกาแฟสมมติสำหรับใช้สอน — ร้านเล็กๆ ในโครงการคอมมูนิตี้มอลล์ เปิด 07:00–18:00 ทุกวัน
ขายกาแฟ เครื่องดื่มอื่น และเบเกอรี่ มีระบบสมาชิกสะสมแต้ม (10 บาท = 1 แต้ม) และขายผ่าน Grab / LINE MAN ด้วย

## ไฟล์ในโฟลเดอร์

| ไฟล์ | เนื้อหา |
|---|---|
| `products.xlsx` | เมนู 14 รายการ: รหัส, ชื่อ, หมวด, ราคาขาย, ต้นทุน, กำไรต่อหน่วย |
| `customers.xlsx` | สมาชิก 25 คน: ชื่อ, เบอร์, วันสมัคร, แต้มสะสม, ระดับ (Bronze/Silver/Gold) |
| `sales.xlsx` | ยอดขายรายบิล 1,030 รายการ (1 มิ.ย. – 20 ก.ค. 2026) พร้อมเวลา, ช่องทาง, รหัสสมาชิก |
| `emails/` | อีเมล 4 ฉบับที่ "เพิ่งเข้ามา" — supplier ขึ้นราคา, ลูกค้าจ้างออกบูธ, Grab ชวนร่วมแคมเปญ, ตึกแจ้งตัดไฟ |

> ข้อมูลทั้งหมดเป็นข้อมูลสมมติที่สร้างขึ้นเพื่อการสอน แต่จงใจฝัง "เรื่องราว" ไว้ให้วิเคราะห์เจอ — ดูเฉลยในไฟล์ `../02-cowork-demo-script.md`
