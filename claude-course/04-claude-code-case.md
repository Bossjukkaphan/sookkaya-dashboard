# เคส Claude Code: สร้างระบบ Dashboard ให้ร้านกาแฟ (40 นาที)

> เป้าหมายของช่วงนี้ **ไม่ใช่สอนเขียนโค้ด** — แต่ให้เห็นว่า "คนไม่เขียนโค้ดก็สั่งสร้างระบบได้" โดยคุยกับ Claude Code เหมือนคุยกับโปรแกรมเมอร์ประจำร้าน

## ฉากของเคส

เพื่อนเจ้าของร้านกาแฟบ่นว่า: "อยากเห็นยอดขายร้านเป็นกราฟสวยๆ แบบร้านใหญ่เขามีกัน แต่จ้างคนทำโปรแกรมก็แพง"
→ วันนี้เราจะสร้างให้เสร็จใน 15 นาทีต่อหน้าทุกคน จากข้อมูลจริงของร้าน

## เตรียมการ

1. สร้างโฟลเดอร์ใหม่ เช่น `coffee-dashboard` แล้วก็อปโฟลเดอร์ `claude-code-case/data/` (มี sales.csv, products.csv, customers.csv) ใส่เข้าไป
2. เปิด Claude Code ในโฟลเดอร์นั้น (หรือใช้ Cowork ก็ทำเคสนี้ได้เช่นกัน — เลือกตามเครื่องมือที่ผู้เรียนเข้าถึงง่ายกว่า)

## Prompt หลัก (พิมพ์ได้เลย)

> ในโฟลเดอร์ data มีไฟล์ sales.csv, products.csv, customers.csv ของร้านกาแฟ
> ช่วยสร้างเว็บ Dashboard เป็นไฟล์ index.html **ไฟล์เดียว** เปิดในเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งอะไร
> ให้ฝังข้อมูลจาก CSV ลงในไฟล์เลย และแสดงเป็นภาษาไทย:
> 1. ตัวเลขสรุปด้านบน: ยอดขายรวม, จำนวนบิล, ยอดเฉลี่ยต่อบิล, กำไรรวม
> 2. กราฟยอดขายรายวัน
> 3. เมนูขายดี 5 อันดับ และเมนูทำกำไรสูงสุด 5 อันดับ (เทียบกันให้เห็น)
> 4. สัดส่วนช่องทางขาย หน้าร้าน / Grab / LINE MAN
> 5. ยอดขายรายชั่วโมง ให้เห็นช่วงพีค
> ธีมสีโทนน้ำตาลกาแฟ ดูสะอาด ทันสมัย

รอสร้างเสร็จ → ดับเบิลคลิกเปิด `index.html` ให้ทุกคนดู (โมเมนต์ว้าวของคลาส)

## สั่งแก้สดๆ ต่อหน้าคลาส (สำคัญกว่า prompt แรก!)

ให้ผู้เรียนช่วยกันสั่ง เพื่อให้เห็นว่าการแก้โปรแกรม = พิมพ์บอกเป็นภาษาคน:

- "เพิ่มช่องค้นหาสมาชิกด้วยเบอร์โทร แสดงชื่อ แต้มสะสม และระดับสมาชิก"
- "เพิ่มกราฟเทียบยอดวันธรรมดากับเสาร์-อาทิตย์"
- "เปลี่ยนธีมเป็นโหมดมืด"
- "เพิ่มปุ่มดาวน์โหลดรายงานสรุปเป็นข้อความ"

## ประเด็นที่ต้องพูดปิดช่วงนี้

1. สิ่งที่เพิ่งเกิดขึ้น: จากไฟล์ Excel ธรรมดา → เป็นระบบใช้งานจริงได้ ภายในไม่กี่นาที โดยไม่เขียนโค้ดเองสักบรรทัด
2. ระบบจริงจังกว่านี้ (เชื่อมเครื่อง POS, อัปเดตอัตโนมัติ, ใช้หลายสาขา) ก็เริ่มจากการ "คุย" แบบเดียวกันนี้ — แค่คุยหลายรอบขึ้น
3. ชวนคิดต่อ: "ระบบอะไรในงานของคุณ ที่อยากได้มานานแต่คิดว่าต้องจ้างคนทำ?" — ให้แต่ละคนตอบ 1 อย่าง เก็บเป็นการบ้าน

## แผนสำรองถ้าเน็ต/เครื่องมีปัญหา

สร้าง dashboard เวอร์ชันเสร็จแล้วเก็บไว้ล่วงหน้า 1 ไฟล์ก่อนวันสอน (รันตาม prompt ข้างบนที่บ้าน) — ถ้าเดโม่สดสะดุด ให้เปิดไฟล์สำเร็จโชว์ แล้วเล่าขั้นตอนแทน
