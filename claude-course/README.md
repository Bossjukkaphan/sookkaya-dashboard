# คอร์ส "ใช้ Claude ทำงานจริง" สำหรับมือใหม่ (3 ชั่วโมง จบในครั้งเดียว)

ชุดเอกสารและไฟล์ประกอบการสอนทั้งหมดสำหรับคอร์สครั้งเดียวจบ 3 ชั่วโมง
สอนเพื่อนที่ **ไม่มีพื้นฐาน AI มาก่อนเลย** ให้ใช้ Claude (Cowork + Claude Code) ทำงานได้จริง

## โครงสร้างโฟลเดอร์

| ไฟล์/โฟลเดอร์ | ใช้ทำอะไร |
|---|---|
| `01-lesson-plan.md` | แผนการสอน 3 ชั่วโมง แบ่งเวลาเป็นช่วงๆ พร้อมเนื้อหาช่วงปูพื้นฐาน 15 นาที |
| `02-cowork-demo-script.md` | สคริปต์เดโม่ Cowork ทีละขั้น พร้อม prompt ที่พิมพ์ได้เลย และเฉลย insight ที่ซ่อนอยู่ในข้อมูล |
| `03-workshop.md` | โจทย์เวิร์กช็อปให้ผู้เรียนลองเองกับไฟล์ของตัวเอง + โจทย์สำรอง |
| `04-claude-code-case.md` | เคสสอน Claude Code — สร้างเว็บ Dashboard ร้านกาแฟจากข้อมูลจริง |
| `05-cheat-sheet.md` | เอกสารแจก 1 หน้า สูตรการสั่งงาน + ตัวอย่าง prompt |
| `06-teaching-script.md` / `.pdf` | สคริปต์พูดคำต่อคำ ครบ 17 สไลด์ทุกช่วง + คำถามที่มักเจอ (คู่กับสไลด์ Canva 17 หน้า) |
| `07-canva-playbook.md` / `.pdf` | คู่มือ "สั่ง Claude ทำสไลด์ใน Canva" — ท่ามาตรฐาน 5 ขั้น, กับดัก 6 ข้อ, prompt สำเร็จรูป + **แผนสอนทีม 45 นาที** |
| `slides.pptx` | สไลด์ประกอบการสอน 15 แผ่น ธีม scrapbook แดง-เหลือง (มี speaker notes ทุกแผ่น) |
| `fonts/` | ฟอนต์ Chonburi (หัวเรื่อง) + Sarabun (เนื้อความ) — **ติดตั้งบนเครื่องที่ใช้สอนก่อนเปิดสไลด์** (ดับเบิลคลิกไฟล์ .ttf แล้วกด Install) ฟอนต์ฟรีจาก Google Fonts สัญญาอนุญาต OFL |
| `demo-coffee-shop/` | **โฟลเดอร์เดโม่** ร้านกาแฟ "บ้านกาแฟหอมละมุน" — ตารางลูกค้า/สินค้า/ยอดขาย (.xlsx) + อีเมลตัวอย่าง 4 ฉบับ |
| `claude-code-case/data/` | ข้อมูลชุดเดียวกันในรูป .csv สำหรับช่วง Claude Code |

## วิธีเตรียมก่อนวันสอน

1. ดาวน์โหลดโฟลเดอร์ `demo-coffee-shop/` ไปวางไว้บนเครื่องที่ใช้เดโม่ (เช่น Desktop)
2. เปิด Cowork แล้วชี้ให้เห็นว่าเลือกทำงานกับโฟลเดอร์นี้ได้
3. ซ้อมเดโม่ตาม `02-cowork-demo-script.md` อย่างน้อย 1 รอบ
4. พิมพ์ `05-cheat-sheet.md` แจกผู้เรียน (หรือส่งไฟล์เข้ากลุ่มไลน์)
5. แจ้งผู้เรียนล่วงหน้าให้ **เตรียมไฟล์งานจริงของตัวเองมาคนละ 1–3 ไฟล์** (Excel, PDF, Word อะไรก็ได้) — สำคัญมาก ถ้าไม่มีไฟล์ตัวเอง เวิร์กช็อปจะไม่สนุก
