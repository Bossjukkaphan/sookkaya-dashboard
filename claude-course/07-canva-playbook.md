# คู่มือ: สั่ง Claude ทำพรีเซนเทชั่นใน Canva

> คู่มือนี้สรุปจากการทำงานจริง — สไลด์คอร์ส 17 หน้าในโปรเจกต์นี้ สร้างด้วยวิธีในเอกสารนี้ทั้งหมด
> ใช้ได้กับ Claude ที่ผูก **Canva connector** ไว้แล้ว (ทั้งใน Chat, Cowork และ Claude Code)

---

## ตอนที่ 1 — เข้าใจภาพรวมก่อน (สำคัญมาก)

### Claude ทำอะไรกับ Canva ได้ / ไม่ได้

| ทำได้ ✅ | ทำไม่ได้ / ทำได้ไม่ดี ❌ |
|---|---|
| ก็อปงาน/ template เป็นชิ้นใหม่ | วาดกราฟิกใหม่ที่สวยเท่า template |
| อ่านทุกข้อความในทุกหน้า | เปลี่ยนฟอนต์ให้เป็นฟอนต์ที่ template ไม่ได้ใช้ |
| **แทนที่ข้อความทีละกล่อง** ← ท่าหลัก | ย้าย/ยืดกล่องให้สวยโดยไม่เห็นภาพ (ต้องดูทีละครั้ง) |
| สลับ/แทรก/ลบ/ก็อปหน้า | สร้างหน้าเปล่าแล้วจัดวางให้สวยเท่าหน้า template |
| Export เป็น PDF / PPTX / PNG | แก้ template ต้นฉบับของ Canva (ต้องก็อปก่อน) |

### 💡 หลักคิดที่ทำให้งานออกมาสวย

> **อย่าให้ Claude "ออกแบบ" — ให้ Claude "เติมข้อความลงในดีไซน์ที่สวยอยู่แล้ว"**

เพราะถ้าให้สร้างหน้าเปล่าเอง จะได้หน้าตาธรรมดา แต่ถ้าเอา template สวยๆ มาแล้วให้เปลี่ยนแค่ข้อความ จะได้งานระดับมืออาชีพทันที — **นี่คือความลับข้อเดียวของทั้งคู่มือนี้**

## ตอนที่ 2 — ท่ามาตรฐาน 5 ขั้น (ใช้ได้ทุกงาน)

### ขั้นที่ 0 — หา template ที่ชอบใน Canva ก่อน

1. เข้า canva.com → ค้นหา "งานนำเสนอ" หรือธีมที่ชอบ
2. เปิด template นั้น กด **Share → Copy link** (หรือกดใช้ template แล้วก็อป URL จาก address bar)
3. เอาลิงก์นั้นมาให้ Claude

> ⚠️ **ต้องเป็นลิงก์ที่เปิดจากบัญชีคุณเอง** — ถ้าเป็นลิงก์ template หน้าเว็บสาธารณะ (canva.com/templates/...) Claude จะเข้าไม่ได้ ให้กด "ใช้ template นี้" ให้มันเข้ามาอยู่ในบัญชีเราก่อน แล้วค่อยก็อปลิงก์

### ขั้นที่ 1 — สั่งก็อปเป็นชิ้นใหม่ (อย่าแก้ต้นฉบับ)

**พิมพ์ว่า:**
```
นี่คือ template ที่ผมชอบ [วางลิงก์]
ช่วยก็อปเป็นงานใหม่ให้ผมหน่อย ตั้งชื่อว่า "[ชื่อที่ต้องการ]"
อย่าแก้ไฟล์ต้นฉบับนะ
```

### ขั้นที่ 2 — ให้ Claude สำรวจก่อนว่า template มีหน้าแบบไหนบ้าง

**พิมพ์ว่า:**
```
อ่านงานที่ก็อปมา แล้วบอกผมว่าแต่ละหน้าเป็นเลย์เอาต์แบบไหน
เช่น หน้าไหนเป็นหน้าปก หน้าไหนมี 4 ช่อง หน้าไหนมีกราฟ
ผมจะได้เลือกว่าเนื้อหาไหนควรอยู่หน้าแบบไหน
```

> 💡 **ขั้นนี้ห้ามข้าม** — เพราะเราจะ "เลือกเลย์เอาต์ให้เหมาะกับเนื้อหา" ไม่ใช่ "ยัดเนื้อหาลงหน้าที่มี"
> ตัวอย่างจากคอร์สนี้: เนื้อหา "AI ทำได้ 4 อย่าง" → ใช้หน้า 4 ช่อง / "3 ระดับ" → ใช้หน้า 3 เกจ

### ขั้นที่ 3 — บอกเนื้อหาทั้งหมด แล้วสั่งเติม

**พิมพ์ว่า:**
```
ผมจะทำสไลด์เรื่อง [หัวข้อ] จำนวน [N] หน้า สำหรับ [กลุ่มผู้ฟัง]
เนื้อหาแต่ละหน้า:
หน้า 1: [หัวข้อ] — [รายละเอียด]
หน้า 2: [หัวข้อ] — [รายละเอียด]
...

ช่วยจัดเนื้อหาลงหน้า template ที่เหมาะสม แล้วเติมข้อความให้ทุกหน้า
ถ้าจำนวนหน้าไม่พอ ให้ก็อปหน้าเลย์เอาต์ที่เหมาะสมมาใช้ซ้ำได้
ข้อความต้องสั้นพอดีกรอบ ไม่ล้น
```

### ขั้นที่ 4 — ตรวจแล้วสั่งแก้

Claude จะส่งภาพตัวอย่างแต่ละหน้ามาให้ดูระหว่างทำ **ดูทุกหน้า** แล้วสั่งแก้ได้เลย:
```
หน้า 5 ข้อความล้นกรอบ ช่วยย่อให้สั้นลง
หน้า 8 เปลี่ยนหัวข้อเป็น "..."
สลับหน้า 3 กับหน้า 4
```

### ขั้นที่ 5 — สั่งบันทึกและ export

```
บันทึกงานทั้งหมด แล้ว export เป็น PDF ให้ผมด้วย
```

## ตอนที่ 3 — ท่าพิเศษที่ใช้บ่อย

### 🔧 ท่าที่ 1: อยากได้หน้ามากกว่า template มีให้

Template ส่วนใหญ่มี 10 หน้า แต่เราอยากได้ 17 หน้า — **ก็อปหน้าเลย์เอาต์เดิมมาใช้ซ้ำ**

```
ผมอยากได้ 17 หน้า แต่ template มี 10 หน้า
ช่วยก็อปหน้าที่เป็นเลย์เอาต์ 4 ช่อง มาใช้ซ้ำอีก 3 ครั้ง
และหน้าเลย์เอาต์ 3 เกจ อีก 4 ครั้ง แล้วเรียงตามลำดับเนื้อหาที่ผมให้ไป
```
> ✅ ได้หน้าใหม่ที่ยังสวยเท่าเดิม เพราะเป็นเลย์เอาต์ template แท้ (ไม่ใช่หน้าเปล่า)

### 🔧 ท่าที่ 2: อยากแทรกหน้าใหม่ตรงกลาง (หลังทำเสร็จแล้ว)

```
ช่วยแทรกสไลด์ใหม่ 1 หน้าเรื่อง [หัวข้อ] โดยเลือกตำแหน่งที่เหมาะกับลำดับการเล่า
ใช้เลย์เอาต์ template แบบเดียวกับหน้าอื่น
```
> 💡 ปล่อยให้ Claude เลือกตำแหน่งเองได้ — มันเห็นเนื้อหาทั้งเล่มแล้วว่าควรแทรกตรงไหน

### 🔧 ท่าที่ 3: เอา template มาใช้กับเนื้อหาที่มีอยู่แล้ว

ถ้ามีสไลด์/เอกสารเดิมอยู่แล้ว:
```
ผมมีเนื้อหาสไลด์เดิมอยู่ในไฟล์นี้ [แนบไฟล์ หรือ ชี้โฟลเดอร์ใน Cowork]
ช่วยเอาเนื้อหาทั้งหมดไปใส่ใน template Canva ตัวนี้ [ลิงก์]
โดยคงจำนวนหน้าและรายละเอียดเดิมไว้ครบ
```

### 🔧 ท่าที่ 4: ขอไฟล์ไปใช้ต่อ

```
export เป็น PDF (เอาไว้ฉายสอน หน้าตาตรงเป๊ะ)
export เป็น PPTX (เอาไว้แก้ต่อใน PowerPoint)
export เป็น PNG หน้า 1 (เอาไว้ทำ thumbnail)
```

## ตอนที่ 4 — กับดัก 6 ข้อที่เจอจริง + วิธีแก้

| # | อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|---|
| 1 | **ตัวหนังสือไทยหายวรรณยุกต์** บนหัวเรื่องใหญ่ | ฟอนต์ display บาง template ไม่มี glyph วรรณยุกต์ที่ขนาดใหญ่มาก | เปลี่ยนคำที่ไม่มีวรรณยุกต์ หรือย้ายคำนั้นไปบรรทัดรอง — สั่งว่า *"หัวเรื่องหน้านี้วรรณยุกต์หาย ช่วยเปลี่ยนคำ"* |
| 2 | **ข้อความล้นกรอบ / ตกขอบ** | ข้อความไทยยาวกว่าที่ template เผื่อไว้ | สั่ง *"ย่อข้อความหน้านี้ให้พอดีกรอบ"* — Claude ย่อและลดขนาดฟอนต์ให้ |
| 3 | **ขอ "สร้างสไลด์ใหม่ 15 หน้า" แล้วรอนาน/ไม่สำเร็จ** | ฟีเจอร์ generate อัตโนมัติใช้เวลานานเกิน | อย่าใช้ท่าสร้างอัตโนมัติ — ใช้ท่าก็อป template + เติมข้อความแทน (เร็วกว่าและสวยกว่า) |
| 4 | **Claude ขอ approve ทุกครั้งที่จะแก้** | เป็นระบบความปลอดภัยของ connector | กด approve ได้เลย ถ้าเป็นงานที่เราสั่งเอง (แนะนำ: ให้ก็อปก่อนเสมอ จะได้ไม่กระทบต้นฉบับ) |
| 5 | **ลิงก์ดาวน์โหลดใช้ไม่ได้ / หมดอายุ** | ลิงก์ export มีอายุ ~1 วัน | ขอ export ใหม่ได้เสมอ หรือเข้า Canva กด Share → Download เอง |
| 6 | **หน้าที่ Claude สร้างเองดูโล่งๆ ไม่เข้าชุด** | หน้าเปล่าไม่มีลายกราฟิกของ template | อย่าให้สร้างหน้าเปล่า — สั่งให้ **ก็อปหน้าเลย์เอาต์เดิม** มาใช้เสมอ |

## ตอนที่ 5 — Prompt สำเร็จรูป (ก็อปไปใช้ได้เลย)

**เริ่มงานใหม่จาก template**
```
ก็อป template นี้เป็นงานใหม่ชื่อ "[ชื่อ]" [ลิงก์]
แล้วบอกผมว่าแต่ละหน้าเป็นเลย์เอาต์แบบไหน
```

**เติมเนื้อหาทั้งเล่ม**
```
เติมเนื้อหานี้ลงงานที่ก็อปมา จัดให้เหมาะกับเลย์เอาต์แต่ละหน้า
ข้อความสั้น กระชับ ไม่ล้นกรอบ ภาษาไทยอ่านง่ายสำหรับ [กลุ่มผู้ฟัง]
[วางเนื้อหา]
```

**ขอสคริปต์พูดคู่กับสไลด์** ← ท่านี้คุ้มมาก
```
ช่วยเขียนสคริปต์พูดสำหรับสไลด์ชุดนี้ ทีละหน้า
บอกด้วยว่าแต่ละหน้าควรพูดกี่นาที เป้าหมายของหน้านั้นคืออะไร
และจังหวะไหนควรถามผู้ฟัง — ทำเป็น PDF ให้ด้วย
```

**ตรวจงานก่อนใช้จริง**
```
ไล่ดูทุกหน้าอีกรอบ เช็คว่ามีข้อความล้นกรอบ ตกหล่น หรือพิมพ์ผิดไหม
ถ้ามีให้แก้ให้เลย
```

**แก้ทีหลัง (คนละวัน คนละแชท)**
```
ช่วยแก้งาน Canva นี้ให้หน่อย [วางลิงก์งานของเรา]
หน้า 5 เปลี่ยนข้อความเป็น "..."
```

## ตอนที่ 6 — เช็คลิสต์ก่อนเอาไปใช้จริง

- [ ] ดูครบทุกหน้าด้วยตาตัวเอง (อย่าเชื่อว่าเสร็จแล้วสวยทุกหน้า)
- [ ] เช็คข้อความล้นกรอบ โดยเฉพาะหน้าที่ข้อความยาว
- [ ] เช็คหัวเรื่องไทยว่าวรรณยุกต์ครบ
- [ ] เช็คตัวเลข/ชื่อ/วันที่ ว่าตรงกับข้อมูลจริง ← **สำคัญที่สุด**
- [ ] Export PDF เก็บไว้ 1 ชุด (กันเน็ตล่มวันนำเสนอ)
- [ ] เปิดลองบนจอที่จะใช้จริง

```
1. หา template สวยๆ ใน Canva → ก็อปลิงก์

4. ดูภาพที่ส่งมา → สั่งแก้จนพอใจ
```

- [ ] แจ้งทีมให้ **สมัคร Canva** และ **เชื่อม Canva connector ใน Claude** มาให้เรียบร้อย (ข้อนี้สำคัญสุด ถ้าไม่ทำมาก่อน จะเสียเวลาในคลาส 20 นาที)

- [ ] ผู้สอนเลือก template กลางไว้ 1 อัน สำหรับคนที่เลือกไม่ถูก

## ลำดับการสอน 45 นาที

| เวลา | ช่วง | ทำอะไร |
|---|---|---|
| 0–5 | **เปิดด้วยผลลัพธ์** | เปิดสไลด์ที่เราทำเสร็จแล้วให้ดู แล้วบอกว่า *"ทั้งชุดนี้ผมไม่ได้ลากกล่องข้อความเองสักอัน"* — ให้เห็นปลายทางก่อน |
| 5–12 | **สอนหลักคิดข้อเดียว** | เปิดตอนที่ 1 → ย้ำ *"อย่าให้ AI ออกแบบ ให้ AI เติมข้อความในดีไซน์ที่สวยอยู่แล้ว"* อธิบายว่าทำไมถึงได้ผลกว่า |
| 12–25 | **เดโม่สด 5 ขั้น** | ทำให้ดูจริงตั้งแต่ก็อป template → เติมเนื้อหา → export ใช้เนื้อหาสมมติสั้นๆ 5 หน้าพอ **อย่าเดโม่งานยาว** |
| 25–40 | **ให้ทีมลงมือทำเอง** | ทุกคนทำกับเนื้อหาจริงที่เตรียมมา ผู้สอนเดินช่วย |
| 40–45 | **โชว์ผลงาน + ปิด** | อาสาสมัคร 2 คนโชว์ แล้วแจกเช็คลิสต์ตอนที่ 6 |

| "ทำไมของผมออกมาไม่สวยเท่าตัวอย่าง" | เช็ก 2 อย่าง: (1) เลือก template สวยหรือยัง (2) ปล่อยให้มันสร้างหน้าเปล่าเองหรือเปล่า — ต้องสั่งให้ก็อปหน้าเลย์เอาต์เดิมมาใช้ |
| "ข้อความล้นกรอบทำไงดี" | สั่ง "ย่อข้อความหน้านี้ให้พอดีกรอบ" — ไม่ต้องไปแก้เองใน Canva |
| "แก้ต่อวันหลังได้ไหม" | ได้ แค่วางลิงก์งานของเราแล้วบอกว่าจะแก้อะไร (ดูตอนที่ 5) |
| "จะรู้ได้ไงว่ามันทำถูก" | **ต้องดูทุกหน้าด้วยตาตัวเองเสมอ** โดยเฉพาะตัวเลขกับชื่อ — ใช้เช็คลิสต์ตอนที่ 6 |

## 💡 เคล็ดลับสำหรับผู้สอน

1. **เดโม่ด้วยเนื้อหาที่ทีมคุ้นเคย** เช่น รายงานประจำเดือนของแผนกเรา — คนจะอินกว่าเนื้อหาสมมติ
2. **ทำผิดให้ดูด้วย** — ลองสั่งสั้นๆ ว่า "ทำสไลด์ให้หน่อย" แล้วเทียบกับสั่งแบบละเอียด ให้เห็นความต่าง
3. **อย่าสอนทุกท่าในวันเดียว** — วันแรกเอาแค่ 5 ขั้นพื้นฐานให้แม่น ท่าพิเศษ (ตอนที่ 3) ไว้รอบสอง
4. **ให้การบ้าน 1 ชิ้น** — ทำสไลด์งานจริง 1 ชุดภายในสัปดาห์นี้ แล้วส่งในกลุ่ม คนจะได้ไม่ลืม
5. **ตั้งคลัง template ของทีม** — รวมลิงก์ template ที่ใช้บ่อยไว้ที่เดียว ทีมจะได้งานหน้าตาเป็นแนวเดียวกันทั้งบริษัท
