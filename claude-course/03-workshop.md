# เวิร์กช็อป: ลองกับไฟล์และโฟลเดอร์ของตัวเอง (45 นาที)

> **แจ้งผู้เรียนล่วงหน้าก่อนวันเรียน:** เตรียมไฟล์งานจริงมาคนละ 1–3 ไฟล์ (Excel, PDF, Word, รูปเอกสาร — อะไรก็ได้ที่เจอบ่อยในงานตัวเอง) ใส่ USB หรือส่งเข้าอีเมลตัวเองมา

## ขั้นตอน (บอกผู้เรียนทีละสเต็ป)

1. สร้างโฟลเดอร์ใหม่บน Desktop ชื่อ `my-workshop` แล้วลากไฟล์งานของตัวเองใส่
2. เปิด Cowork ชี้ไปที่โฟลเดอร์นั้น
3. เริ่มจาก prompt แรกเสมอ:
   > อ่านไฟล์ในโฟลเดอร์นี้ แล้วบอกว่าเห็นข้อมูลอะไรบ้าง และคิดว่าช่วยอะไรฉันได้บ้าง
   (ให้ Claude เสนอไอเดียเอง — มือใหม่มักคิดไม่ออกว่าจะสั่งอะไร)
4. เลือกไอเดียที่ Claude เสนอมา 1 อย่าง แล้วสั่งทำจริง โดยใช้สูตร **บทบาท + งาน + บริบท + รูปแบบผลลัพธ์**
5. ผลลัพธ์ไม่ถูกใจ → พิมพ์บอกให้แก้ อย่างน้อย 2 รอบ (ฝึกนิสัยคุยต่อเนื่อง)
6. ปิดท้าย: สั่งให้ Claude **สร้างไฟล์ผลลัพธ์** (รายงาน .md, ตาราง Excel, ฯลฯ) เก็บไว้ในโฟลเดอร์

## โจทย์สำรอง (สำหรับคนไม่มีไฟล์มา)

ให้ก็อปโฟลเดอร์ `demo-coffee-shop/` ไปใช้ แล้วเลือกทำ 1 ข้อ:

- **โจทย์ A (ง่าย):** "หาลูกค้าสมาชิก 5 คนที่แต้มเยอะสุด แล้วร่างข้อความขอบคุณส่งไลน์ให้แต่ละคน แบบเป็นกันเอง"
- **โจทย์ B (กลาง):** "ร่างใบเสนอราคาบูธกาแฟตามอีเมลของบริษัทสยามเทค งบไม่เกิน 18,000 บาท เลือกเมนูจาก products.xlsx ที่กำไรดีและชงเร็ว"
- **โจทย์ C (ยาก):** "ออกแบบโปรโมชั่นวันธรรมดาช่วงบ่าย (ช่วงที่ยอดต่ำสุด) โดยใช้ข้อมูลจริงจาก sales.xlsx อ้างอิงประกอบ แล้วสรุปเป็นโปสเตอร์ข้อความ 1 หน้า"

## บทบาทผู้สอนระหว่างเวิร์กช็อป

- เดินวนช่วยทีละคน — ปัญหาอันดับ 1 ของมือใหม่คือ "สั่งสั้นเกินไป" → ชี้ให้เติมบริบทกับรูปแบบผลลัพธ์
- ใครทำเสร็จเร็ว ให้ลองสั่งงานซ้อน เช่น "ทำแบบเดิมแต่เป็นภาษาอังกฤษ" หรือ "ทำเป็น Excel แทน"
- เก็บ 10 นาทีสุดท้ายให้ 2–3 คนโชว์ผลงานหน้าห้อง — ตัวอย่างจากเพื่อนจุดประกายได้ดีกว่าตัวอย่างผู้สอน
